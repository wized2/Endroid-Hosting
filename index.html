How to Host a Static Website for Free on Endroid Host

  1. Choose a name: Enter a custom site name or leave it blank.
  2. Upload files: Drag and drop your HTML, CSS, and JS files, or select an entire folder.
  3. Or use the code editor: Switch to the "Editor" tab and write your HTML directly.
  4. Click Publish: Your site will be live instantly at e-host.zone.id/your-site/.
